Word报告和在线正文使用相同章节。报告包含20张微信开发者工具模拟器原图和4张按实际代码及状态流程绘制的说明图。来源登记明确区分运行截图与流程图；摄影样图许可见[素材说明](../../assets/demo-products/README.md)。

排版按课程展示报告设置：A4纵向、约2.5厘米页边距，正文黑色宋体12磅、1.5倍行距；标题、页眉、页码和表格文字均为黑色。截图保留软件页面原有配色。

如果功能、接口或测试证据后续变化，应在同一项目中同步更新 Word、在线正文、相关截图和来源清单，再从仓库首页确认链接指向 `main`。原始需求分析与设计说明书保持不变，差异记入[变更记录](../changes.md)。
