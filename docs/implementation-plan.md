## 固定业务规则

- 学籍匹配后人工认证；未认证、禁用用户不能发布。姓名、电话和学号加密存储，学号HMAC唯一索引，公开资料脱敏。
- 商品标题2～50字、描述非空、价格非负整数分、1～9张≤5MiB图片；未审核商品不可公开读取。
- 同卖家24小时规范化标题和价格相同视为重复；在事务中锁卖家行再检查。每分钟最多成功发布5件，信誉<60限制发布。
- 发布/编辑进入待审；审核通过才能上架；锁定、售出和冻结商品不能被卖家修改。接口提交动作而非任意状态。
- Controller/Service/Repository分层；真实MySQL持久化；统一返回结构和错误码；关键操作保留非敏感日志。
