## 试用入口

运行环境沿用根README，执行 `scripts/start.ps1`，微信开发者工具导入 `miniprogram`。本机后端为 `http://127.0.0.1:3000`，不是浏览器网页，需在工具模拟器中操作。

- 买家：商品详情可咨询、收藏、举报及下单；“我的”可查看订单、咨询、收藏和举报结果。
- 卖家：切换为陈同学，进入“我的订单 → 我卖出的”，完成接单、开始交割、标记已交付。
- 买家确认后可评价；支付、退款均为课堂模拟，不产生资金变动。
- 管理员：“我的 → 监管工作台”，可审核认证/商品、处置举报、管理账号、分类和规则。
- 退出后在登录页切换演示身份。口令只从本地 `.env` 的 `DEMO_PASSWORD` 读取，禁止写入GitHub。

请保留四件原始摄影样品；自动页面检查只使用名称以“联调试用”开头的新增虚构样品。
