# 校园拾集界面风格与截图

首页以橙红建立购物氛围，黄、蓝、绿分别用于低价入口、教材和宿舍分类、认证信誉。商品图片与白色卡片保持清晰，价格和交易动作突出显示；个人与监管页面使用校园绿色，咨询页用浅蓝区分双方消息。
