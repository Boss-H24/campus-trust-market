# 统一项目本机试用说明

本机试用以仓库唯一交付分支 `main` 为准。启动方式和微信开发者工具导入步骤见[项目首页](../README.md)。服务端地址是 `http://127.0.0.1:3000`，页面运行在微信开发者工具模拟器内。

## 试用流程

- 买家：搜索商品、查看详情、咨询、收藏、举报并创建订单。
- 卖家：进入“我的订单 → 我卖出的”，接单、开始交割并标记已交付。
- 买家确认收货后可评价；支付和退款是模拟业务，不产生真实资金变动。
- 管理员：进入“监管工作台”，审核认证和商品、调查举报、管理冻结、账号、分类及规则。
- 退出后在登录页切换虚构演示身份。密码仅从本机 `.env` 的 `DEMO_PASSWORD` 读取，不要复制进 GitHub 或课堂PPT。

数据库保留原有四件摄影样例商品；自动验收添加的商品使用“课堂展示”字样并标明为虚构样品。演示订单和处理记录可用于课堂讲解。
